# SOL페이 공개 화면 분석 및 한프레임 적용

분석일: 2026-11-03

**금융 어플이라 미러링 중 중단하고 공개 자료 분석으로 전환한다.**

맥의 iPhone 미러링 연결만 확인했으며, SOL페이 로그인 이후의 실제 내부 화면이나 전체 동선을 탐색하지 않았다. 사용자의 요청에 따라 공개 화면 기준으로 진행했다. Mobile MCP로 앱 전체를 분석한 결과가 아니다. 미러링 중 보인 개인 금융정보나 화면은 제출물에 포함하지 않는다.

## 근거
- [App Store 공식 소개 및 스크린샷](https://apps.apple.com/kr/app/id572462317): 홈·혜택·결제·금융·카드의 5개 탭, 홈의 주요 정보 요약 및 자주 쓰는 메뉴를 확인했다.
- [UIBowl 참고 주소](https://uibowl.io/name/%EC%8B%A0%ED%95%9C%20SOL%ED%8E%98%EC%9D%B4): 확인 당시 ‘선택하신 항목에 해당하는 패턴이 없어요.’로 표시되어 세부 화면을 분석하지 못했다.

## 관찰과 적용
| 공개 자료에서 확인한 요소 | 한프레임 적용 |
|---|---|
| 5개 주요 탭 | 홈·자료 조사·제작·검수·보관함 |
| 홈에서 주요 정보를 요약 | 자료 수·대본 수·검수 상태 |
| 자주 쓰는 메뉴 접근 | 자료 조사 및 제작 바로가기 |
| 파란색 강조와 카드 중심 화면 | 파란 CTA, 흰 카드, 밝은 회색 바탕 |

모바일 하단 메뉴 및 데스크톱 사이드 메뉴는 새 서비스에 맞춘 설계다. 색상값·간격·모서리 반경은 공식 사양을 추출한 값이 아니다.

## 제안 동선 — 실제 앱 관찰과 구분
인물 이름 입력 → 출처와 확인한 요약 저장 → 날짜순 타임라인 → 요약 기반 대본 조립 → 자막 텍스트 입력 → SRT 초안 내보내기 → 원문 대조 → 프로젝트 보관.

## 구현 범위
과제 제출용 반응형 프론트엔드다. 브라우저 로컬 저장, 출처 입력, 날짜 정렬, 조사 프롬프트 복사, 요약을 이어 붙인 대본 초안, TXT/SRT/JSON 내보내기를 제공한다. 자동 웹 수집, 중국어 AI 번역, 음성 파일 자동 전사는 미연결이다. SRT 시간은 일정 간격으로 계산하므로 실제 음성과 맞춰 수정해야 한다.

금융 거래, 개인정보 수집 및 원본 금융 앱 화면 재배포는 포함하지 않는다.
