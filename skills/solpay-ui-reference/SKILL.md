# SOL페이 공개 UI 참고 스킬

## 적용 범위
공개 앱 화면의 정보 구조를 참고해 새로운 서비스의 화면을 설계한다. 신한 로고, 상표, 원본 스크린샷을 서비스 자산으로 복제하지 않는다. 확인하지 않은 내부 동선을 실제 관찰한 것으로 기술하지 않는다.

## 근거 확인
- 앱스토어: https://apps.apple.com/kr/app/id572462317
- UIBowl: https://uibowl.io/name/%EC%8B%A0%ED%95%9C%20SOL%ED%8E%98%EC%9D%B4
- 앱스토어 공개 설명의 홈·혜택·결제·금융·카드 5개 탭과 홈 요약, 자주 쓰는 메뉴 구조를 참고한다.
- 공개 화면은 버전에 따라 달라진다. 적용 시 확인 날짜와 접근 가능한 범위를 기록한다. 자료가 비어 있으면 다른 공식 공개 자료를 사용하고 그 사실을 명시한다.
- 개인정보가 노출되는 금융 앱 탐색은 아이폰 미러링 정책상 불가하여 지속적으로 중단되었으므로, 공개된 화면 캡처를 바탕으로 확인 가능한 범위의 동선을 분석했다.

## 디자인 변환
1. 사용자의 핵심 작업을 4~5개 메뉴로 나눈다. 모바일에는 하단 메뉴, 데스크톱에는 사이드 메뉴를 사용한다.
2. 첫 화면은 주요 작업 버튼, 요약 숫자, 빠른 실행, 이어서 작업하기 순서로 구성한다.
3. 밝은 회색 배경, 흰색 카드, 파란색 주요 버튼, 넉넉한 간격과 둥근 모서리를 사용한다. 이는 참고 화면을 바탕으로 한 설계 선택이며 공식 디자인 토큰이 아니다.
4. 작은 화면에서는 장식보다 본문과 버튼을 우선한다. 메뉴·양식에 텍스트 레이블과 키보드 초점을 제공한다.
5. 구현된 기능과 미연결 기능을 화면에 구분한다. 가짜 진행률이나 생성 결과로 자동화 성공을 가장하지 않는다.

## 중국어 콘텐츠 서비스 적용 예
- 홈: 수집 자료 수, 대본 수, 검수 상태
- 자료 조사: 한자 이름·활동명, 기사·인터뷰·공식 발표 URL, 사건 날짜, 원문 메모, 한국어 요약
- 제작: 확인된 요약 기반 내레이션 초안, 편집, 텍스트 및 SRT 내보내기
- 검수: 인명 표기, 인용문, 날짜·출처, 자막 시간 대조
- 보관함: 프로젝트 저장·가져오기

AI 번역·음성 전사 연결이 없으면 수동 입력과 프롬프트 복사를 제공한다. 일정 간격으로 만든 SRT는 음성 정렬 완료본이 아닌 시간 조정이 필요한 초안으로 표시한다.

## 제출 전 확인
홈과 주요 탭이 열리는지, 작은 화면에서 겹치지 않는지, 저장과 내보내기가 작동하는지 확인한다. 결과에는 사이트 URL, 분석 범위, 실제 구현 기능과 미연결 기능을 짧게 적는다. 공개 저장소에는 개인 이름·잔액·거래내역·기기 식별자·비밀키를 넣지 않는다.
